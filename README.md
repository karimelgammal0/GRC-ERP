# نظام تكاليف مصنع GRC — على Supabase (Postgres)

## التشغيل
```
npm install
npm start          # http://localhost:3000
```
- ملف `.env` فيه `DATABASE_URL` الخاص بمشروع Supabase (**سرّي — ماتشاركوش**). في أول تشغيل النظام بينشئ الجداول ويحمّل بيانات الأصناف والموردين والمشروعات تلقائياً.
- لو مفيش `.env` النظام بيشتغل على Postgres محلي مضمّن (مجلد `data/pgdata`) للتجربة.
- الدخول: `admin` / `admin123` (بيطلب تغيير كلمة المرور).

## أوامر
- `npm test` اختبار السيناريو الكامل (على قاعدة في الذاكرة، مش على Supabase أبداً).
- `npm run reset-db -- --yes` يمسح **كل** جداول قاعدة البيانات (Supabase أو المحلية).

## ملاحظات
- شغّل نسخة واحدة فقط من السيرفر على نفس قاعدة البيانات.
- النسخ الاحتياطي: من Supabase ← Database ← Backups.
- الأرصدة الافتتاحية: الإعدادات ← الأرصدة الافتتاحية (تعديل وتطبيق حتى «قفل الأرصدة»).

## دليل الحسابات
- مصدره `seed/chart-of-accounts.csv` (بيتحمّل في أول تشغيل).
- لو قاعدة البيانات اتهيّأت قبل كده بالدليل القديم: أوقف السيرفر وشغّل `npm run apply-coa` مرة واحدة — بيرحّل الدليل مع الحفاظ على القيود وربط الحسابات.
- بعد كده أي تعديل: من «الحسابات ← دليل الحسابات» (تعديل يدوي أو «استيراد CSV» بنفس شكل التصدير؛ بيحدّث/يضيف بالكود ومبيحذفش).
